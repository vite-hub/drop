# Human-readable documents

Choose the source format first, then compose only the relevant writing skill:

- For a prompt or `SKILL.md`, use `$agent-writing` before publishing.
- For an `.html` source document, use `$html-communication` to create the document. Follow its document rules, then return to ViteHub Drop for delivery. The Drop upload command in `SKILL.md` replaces its Postplan delivery step.
- For a Markdown plan, follow [the Markdown plan guide](markdown.md). Treat `.md` as Markdown authoring even though Drop serves it as HTML.

Apply `$unslop` to the final human-facing prose, then publish the finished file once.
