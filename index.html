How and why

Give agent-made files a place to land

ViteHub Drop publishes files at stable URLs, turns Markdown into readable pages, and renders source code as images. Install the skill once and let your agent handle the rest.

  1. 1

    Upload

    Send Drop one file, up to 4 MiB. Blob stores it immediately; Queue optimizes supported images in the background.

  2. 2

    Get the URL

    The file is available immediately at a permanent drop.vitehub.dev/i/… URL identified by its UUID. A revision gets a new URL.

  3. 3

    Read

    Markdown opens as a Comark-rendered document with callouts and Mermaid diagrams. Add ?raw for its exact source.

Use Drop

Upload a file

The installed skill uploads the file and returns its permanent Drop URL.

curl --fail-with-body --silent --show-error \
  -F "file=@/absolute/path/to/file.pdf" \
  https://drop.vitehub.dev/api/files | jq -er '.url'

Limits

  • One file per request, up to 4 MiB.
  • Target: 5 upload attempts per source address every 60 seconds.
  • On 429, wait one minute before retrying.

Errors

StatusMeaning
400Malformed multipart data, a missing or repeated file, or an unexpected field.
413The file exceeds 4 MiB or the request exceeds 4 MiB plus 64 KiB.
415The request is not multipart data.
422The content type header is malformed.
429The upload rate limit was reached; retry after 60 seconds.
503Rate limiting, storage, or optimization dispatch is unavailable.
Code images

Turn code into an image

Choose a language, theme, scale, and format to get a PNG or SVG.

curl https://drop.vitehub.dev/api/code \
  -H "content-type: application/json" \
  --data '{
    "code": "#include <iostream>\n\nint main() {\n  std::cout << \"Hello\";\n}",
    "language": "cpp",
    "theme": "nuxt",
    "format": "png",
    "scale": 2
  }'

Options

  • format accepts png or svg.
  • scale accepts 2, 4, or 6.
  • language accepts a case-sensitive Ray.so ID such as cpp or typescript.
  • theme accepts a case-sensitive Ray.so ID such as nuxt or midnight.
  • Download the result within five minutes, or upload it to Drop for a permanent URL.
