How and why

Programmatically upload pictures to GitHub

Agents have no easy way to upload images to GitHub because there is no standard MCP tool or ready-made skill. ViteHub Drop provides the missing upload workflow.

  1. 1

    Upload

    The agent uploads the image and gets a temporary DROP_URL.

  2. 2

    Render

    The agent posts ![image](DROP_URL) to a GitHub issue or pull request.

  3. 3

    Post

    GitHub returns a camo.githubusercontent.com URL for the agent to use. How Camo works.

Skill

Upload Image to GitHub

The installed skill includes a script that validates the image, uploads it to Drop, resolves it through GitHub, and prints the Camo URL.

node "<skill-directory>/scripts/upload-image.mjs" "/absolute/path/to/image.png"

Limits

  • One PNG, JPEG, or WebP image per request, up to 4 MiB.
  • Target: 5 upload attempts per source address every 60 seconds.
  • On 429, wait for Retry-After before retrying.

Errors

StatusMeaning
400A missing content type, malformed multipart data, a missing or repeated image, or an unexpected field.
413The image exceeds 4 MiB or the request exceeds 4 MiB plus 64 KiB.
415The request is not multipart data, the image format is unsupported, or its signature does not match the declared type.
422The content type header is malformed.
429The upload rate limit was reached; retry after 60 seconds.
503Rate limiting, storage, or the expiry queue is unavailable.
